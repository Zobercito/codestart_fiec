# Evaluación formativa final

> **Contenido provisional.** Pendiente de revisión por el experto docente.

Esta evaluación recorre los ocho módulos del curso. No es un examen de
memoria: las preguntas piden leer un programa, predecir una salida o
identificar el error.

## Antes de empezar

- Responde todas las preguntas; el botón de entrega se activa al completar
  la última.
- Cada pregunta pertenece a un área. Al final verás el porcentaje por área
  y las que conviene reforzar.
- El umbral de aprobación es el 60 %. Puedes intentarlo de nuevo: cada
  intento queda registrado para que el docente vea el progreso.

## Qué se evalúa

1. Conceptos de hardware, software y memoria.
2. Algoritmos y descomposición de problemas.
3. Compilación, interpretación y anatomía de un programa.
4. Variables, tipos y operadores.
5. Condicionales y ciclos.
6. Arreglos, índices y recorridos.
7. Integración de las piezas en un programa completo.

## Cómo leer una pregunta de código

Si la pregunta muestra un programa, no intentes ejecutarlo mentalmente de
una vez. Haz una tabla con los valores de las variables en cada vuelta o en
cada rama. Para una condición, identifica el límite exacto; para un ciclo,
cuenta las vueltas y comprueba si el índice entra o no.

La evaluación no sustituye la práctica: si un área queda por debajo del
umbral, vuelve a la lección y resuelve el reto antes de repetir.
